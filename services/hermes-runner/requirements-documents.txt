# Series 4 — agent document toolchain (FREE / open-source).
#
# Installed at BUILD time into the golden runner image (see Dockerfile.fly
# runtime stage). These land in the system site-packages the `delegent`
# runtime user can import, so the Hermes agent's `terminal` + `file` toolsets
# can read/write documents out of the box — no runtime pip/apt, which the
# R-UPG-02 forensic guard forbids in the live server path.
#
# Capability coverage (forensic capability tests in tests/forensic/E-agent.test.mjs):
#   R-AGENT-03  summarise/extract PDFs            -> pypdf, pdfplumber, pymupdf
#   R-AGENT-23  multi-PDF research (quote+page)   -> pdfplumber, pymupdf
#   R-AGENT-13  receipt PDF -> date/total/VAT      -> pdfplumber (text+tables) / pymupdf
#   R-AGENT-11  photo OCR (parking-ticket image)  -> pytesseract + Pillow (+ apt tesseract-ocr)
#   (scanned PDF OCR)                              -> pdf2image (+ apt poppler-utils) -> pytesseract
#   R-AGENT-27  cashflow .xlsx (>=3 sheets+chart) -> openpyxl (read/write + native charts)
#   R-AGENT-33  5-slide .pptx                      -> python-pptx
#   (.docx authoring)                              -> python-docx
#   PDF authoring (invoices/letters/reports)      -> reportlab, xhtml2pdf (HTML+CSS -> PDF)
#   PDF form FILLING (fill an existing AcroForm)  -> pypdf (field values + regenerated
#                                                    appearance streams + NeedAppearances, so
#                                                    the value stays an editable/screen-reader
#                                                    field AND is baked visible for printing);
#                                                    pymupdf as the fallback filler + flatten.
#                                                    Single source of truth: the
#                                                    pdf-document-creation skill.
#   CSV / tabular data wrangling                   -> pandas (+ numpy)
#   optional charts as PNG                          -> matplotlib (Agg backend, headless)
#
# Wheel/build notes (verified against PyPI on 2026-05-31, base = python:3.11-slim-bookworm):
#   - All of these resolve to prebuilt wheels for cp311 / manylinux_2_28 x86_64;
#     none compile from source, so no build-essential is needed in the runtime
#     stage (it is intentionally absent there).
#   - pymupdf 1.27.2.3 ships a cp310-abi3 manylinux_2_28 wheel; abi3 wheels are
#     forward-compatible, so pip on Python 3.11 installs it without a source build.
#   - pandas/numpy require Python >=3.11 (satisfied) and ship cp311 wheels.
